# Login & Signup Form Validation

## Project Overview
A responsive Login and Signup form developed using HTML, CSS, and JavaScript. This project provides client-side form validation and a user-friendly interface.

## Features
- Login form validation
- Signup form validation
- Email format validation
- Password length validation
- Confirm password matching
- Password Show/Hide functionality
- Success and error messages
- Login and Signup form switching

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
Login-Form-Validation/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Test the Login and Signup forms.
